## 2024-05-18 - Nested Interactive Element Bubbling Bug
**Learning:** Found an interaction bug in `StudentCabinet.tsx` where an entire task container `div` had an `onClick` to toggle the task, but the container also nested a secondary interactive "Решить" button for FEN parsing. Clicking the inner button would bubble up and accidentally toggle the task's completion state. Placing `onClick` on container `div`s is generally an anti-pattern for accessibility and leads to these types of event bubbling bugs.
**Action:** Moving forward, avoid attaching `onClick` handlers to container `div`s that have nested interactive elements. Always place interactive actions on specific semantic elements (like a checkmark `<button>`) and ensure they are properly labeled with `aria-label` for screen readers and have focus visible styling.
