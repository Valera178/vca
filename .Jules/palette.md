## 2024-03-29 - Accessible Interactive List Items
**Learning:** When making large list items or container components interactive, using a semantic structure with `role="button"` and `tabIndex={0}` is crucial for accessibility. A common mistake is nesting interactive elements (like a toggle button inside the container and another action button), which causes screen reader and keyboard navigation issues.
**Action:** Convert the container to an accessible button with appropriate ARIA attributes (e.g., `aria-pressed`). Change internal visual-only controls (like checkboxes/icons) to non-interactive `<div aria-hidden="true">`. Use `e.stopPropagation()` for both click and keydown events on any genuinely separate interactive child elements to prevent triggering the parent container's action.
