## 2024-04-28 - [Accessible Interactive Container Pattern]
**Learning:** Making large container `div`s interactive (like task lists) requires a specific combination of attributes to be fully accessible without breaking screen readers: `role="button"`, `tabIndex={0}`, `aria-pressed`, and Space/Enter `onKeyDown` handlers. Furthermore, any nested visual-only pseudo-buttons (like status circle icons) *must* be converted to non-interactive elements (e.g. `<div aria-hidden="true">`) to prevent invalid nested interactive element HTML, and any genuinely interactive nested buttons (like "Решить") need `e.stopPropagation()` on both `onClick` and `onKeyDown` to prevent the parent container from intercepting their activation.
**Action:** When converting large list items to be clickable, apply this full pattern instead of just adding `onClick` and `cursor-pointer`.
