## 2026-06-04 - Interactive Nested Components and Container Accessibility
**Learning:** When making large list items (like the tasks container) interactive for better UX, they require `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler for Enter/Space, along with ARIA attributes. However, doing so can cause "nested interactive element" issues if children are also buttons. Furthermore, any inner functional interactive controls (like a specific nested "Solve" button) inside the larger container must have `e.stopPropagation()` on both `onClick` and `onKeyDown` to prevent triggering the outer parent container's actions.
**Action:** Always convert visual-only inner controls to non-interactive elements (e.g. `<div aria-hidden="true">`) and explicitly stop event propagation on functionally separate inner buttons when constructing clickable container elements.
