
## 2023-11-20 - Accessible Interactive List Items
**Learning:** When making large container components (like list items or cards) interactive by putting an `onClick` on a `div` wrapper, it is critical to also make it fully accessible. This includes adding `role="button"`, `tabIndex={0}`, `aria-pressed` (if it toggles state), and an `onKeyDown` handler for 'Enter' and 'Space'. Additionally, inner visual-only controls (like checkboxes) should be converted from `<button>` to `<div aria-hidden="true">` to prevent screen reader confusion with nested interactive elements. If there are genuinely distinct interactive elements inside the container (like a specific action button), they must use `e.stopPropagation()` for both click and keydown events so they don't trigger the parent container's action.
**Action:** When creating or modifying click-to-toggle list containers, ensure they are converted to proper accessible buttons. Ensure inner decorative interactive elements are non-interactive to screen readers, and distinct interactive children block event propagation.
