## 2024-05-15 - Interactive List Items
**Learning:** When making a large container element interactive (like a list item with a visual toggle button inside), adding generic `onClick` handlers creates significant accessibility barriers. Native screen readers will ignore it, and keyboard users cannot activate it. Adding nested interactive elements inside an interactive parent creates HTML validity issues.
**Action:** Preserve the large click target area for UX by making the container `div` accessible using `role="button"`, `tabIndex={0}`, `aria-pressed`, and `onKeyDown` (for Enter/Space). Convert the visual-only inner toggle controls to non-interactive elements (e.g., `<div aria-hidden="true">`). Any functionally separate, nested interactive elements (like an action button) must explicitly prevent event bubbling using `e.stopPropagation()` for both click and keydown events.
