## 2024-03-10 - Avoid onClick on divs with nested buttons
**Learning:** Attaching `onClick` events to generic container `div`s (like a task list item) creates severe accessibility and UX issues. It makes the entire container clickable (but often unreachable via keyboard navigation) and causes nested interactive elements (like an inner "Solve" button) to trigger the parent container's event when clicked, resulting in unintentional behavior (e.g., toggling task completion while trying to open the puzzle).
**Action:** Always place interactive actions on semantic elements (e.g., `<button>`). Ensure complex UI components separate their distinct interactions by avoiding container-level click handlers when inner buttons are present, and properly use `aria-label`, `aria-pressed`, and `focus-visible` styles to handle both visual state and keyboard navigation explicitly.
