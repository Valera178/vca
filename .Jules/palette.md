## 2024-05-08 - Accessible Interactive List Items with Nested Controls
**Learning:** When making large container elements like list items interactive for better UX, nesting other interactive elements (like specific action buttons) creates an accessibility anti-pattern. Screen readers and keyboard navigation may struggle to distinguish between the parent container's action and the child button's action. Additionally, visual-only icons that appear as buttons can confuse standard HTML semantics if not hidden properly.
**Action:** Always follow these steps for complex interactive list items: 1) Add `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler (for Space/Enter) to the main parent container. 2) Apply ARIA states like `aria-pressed` to the parent to reflect its status. 3) Convert any nested, purely visual indicators that look like buttons (e.g., checkmarks) into non-interactive elements like `<div aria-hidden="true">`. 4) For genuinely separate nested actions, use a standard `<button>` with clear `aria-label`s, but importantly, add `e.stopPropagation()` to both its `onClick` and `onKeyDown` handlers to prevent activating the parent container's action.
