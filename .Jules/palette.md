## 2024-05-04 - Accessible Interactive List Items
**Learning:** When making large list items or container components interactive (like task cards), it is important to preserve the large click target area for mouse users while ensuring keyboard and screen reader accessibility. However, this often leads to invalid HTML if interactive elements (like buttons or links) are nested inside the container.
**Action:** Make the container `div` fully accessible by adding `role="button"`, `tabIndex={0}`, and `onKeyDown` handlers for Enter/Space. Crucially, convert inner visual-only controls (like checkmark icons) to non-interactive elements (e.g., `<div aria-hidden="true">`), and use `e.stopPropagation()` on any genuinely separate interactive child elements to prevent event bubbling issues.
