## 2024-05-26 - Accessible Interactive Containers with Nested Actions
**Learning:** When making large list items or container components interactive (like a selectable task card), inner visual-only controls (like checkmarks) can cause nested interactive element issues for screen readers if left as `<button>`. Furthermore, nested genuinely interactive elements (like a "Solve" button) need click/keydown event propagation stopped to prevent double-triggering the parent's action.
**Action:** Convert the container to an accessible element (`role="button"`, `tabIndex={0}`, `aria-pressed`, `onKeyDown` handler for Enter/Space). Convert visual-only inner controls to `<div aria-hidden="true">`. Add `e.stopPropagation()` for both `onClick` and `onKeyDown` to nested independent buttons to preserve functional separation.
