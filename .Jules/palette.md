## 2024-05-27 - Make Interactive Lists Accessible
**Learning:** When making large container components (like list items) interactive to provide a large click target area for UX, screen readers and keyboard users often struggle if inner interactive elements are present. Navigating into a nested interactive item is difficult.
**Action:** Always make the container accessible with `role="button"`, `tabIndex={0}`, `aria-pressed` (if stateful), and keyboard event handlers (`onKeyDown`). Crucially, change any purely visual inner controls (like checkmarks) from `<button>` or `<input>` to non-interactive elements like `<div aria-hidden="true">`. For inner interactive elements that *must* remain separate (like specific action buttons), explicitly add `e.stopPropagation()` to both their `onClick` and `onKeyDown` events to prevent the container's action from firing unintentionally.
