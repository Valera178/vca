## 2026-05-02 - Accessible Interactive Containers and Event Bubbling
**Learning:** When making a large container interactive (like a task list item), wrapping it in an accessible `role="button"` and adding keyboard support (`onKeyDown`) is essential. However, any nested interactive elements (like specific buttons inside the task) must use `e.stopPropagation()` for both click and keydown events. Otherwise, interacting with the nested button will trigger the container's action. Visual-only interactive elements like fake checkbox buttons should be demoted to non-interactive `div` elements with `aria-hidden="true"` to prevent nested interactive element accessibility issues.
**Action:** When creating large click targets with nested actions, ensure the container has full keyboard support (`tabIndex={0}`, `onKeyDown`), demote purely visual nested controls to non-interactive `div`s, and strictly add `e.stopPropagation()` to both click and keydown events on any genuinely separate interactive child elements.
