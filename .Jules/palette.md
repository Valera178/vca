
## 2026-05-31 - Accessible Large Interactive List Items
**Learning:** When making a large container (like a task row) clickable to maximize click target area, inner visual controls (like a checkmark button) can cause nested interactive element issues for screen readers. The container needs `role="button"`, `tabIndex={0}`, keyboard event handlers, and appropriate ARIA attributes (like `aria-pressed`). Inner visual buttons should be converted to non-interactive elements with `aria-hidden="true"`. Any genuinely separate interactive children (like a specific nested action button) require `e.stopPropagation()` on both click and keydown to prevent accidental triggering of the parent.
**Action:** Routinely convert inner visual-only controls to `aria-hidden` divs when making their parent container interactive. Always add complete keyboard support (Enter/Space handlers, role, tabIndex) to interactive containers, and ensure genuine nested interactive elements stop event propagation.
