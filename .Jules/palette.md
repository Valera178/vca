## 2024-05-21 - Accessible Interactive List Items
**Learning:** When making large container components interactive (like a task list item), wrapping it in `role="button"` and `tabIndex={0}` is essential for UX, but it creates a risk of "nested interactive elements" if there are buttons inside it. The inner components (like a checkmark icon or a specific action button) need special handling: visual-only buttons must be converted to non-interactive elements (e.g., `<div aria-hidden="true">`) and genuine action buttons (like "Решить") must use `e.stopPropagation()` for both click and keydown events so they don't trigger the parent container's action.
**Action:** Always audit large clickable cards/rows for nested buttons. Convert purely visual toggles to `div`s with `aria-hidden` and explicitly stop event propagation on real functional sub-buttons to ensure clean keyboard and screen reader experiences.
