## 2024-06-01 - [Interactive Container Accessibility]
**Learning:** When making large list items (like task lists) clickable for better UX, they must be converted to proper interactive elements using `role="button"`, `tabIndex={0}`, and have keyboard support (Space/Enter). Additionally, any purely visual inner controls (like checkboxes) must have `aria-hidden="true"` and not use the `<button>` tag to prevent nested interactive element issues. Finally, any genuinely functional nested buttons (like a "Solve" button inside the task) must use `e.stopPropagation()` for both click and keydown to prevent triggering the parent container's actions.
**Action:** Always ensure containers doubling as buttons are fully keyboard-accessible and manage their children's interactive roles properly to avoid nested button a11y violations.
