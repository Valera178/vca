## 2024-03-24 - Accessible interactive container divs
**Learning:** When making a large container component (like a list item) interactive, using `div` with `onClick` is common but creates accessibility issues. Furthermore, having purely visual elements inside this container as `<button>`s creates nested interactive element warnings for screen readers. Finally, if there are genuine action buttons inside the container, their events must be stopped from propagating to the parent.
**Action:** When adding interactivity to a `div` container, add `role="button"`, `tabIndex={0}`, an `onKeyDown` handler (listening for Space/Enter), and focus styles. Convert nested visual-only interactive elements to `div aria-hidden="true"`. Use `e.stopPropagation()` on both `onClick` and `onKeyDown` for any genuine nested buttons.
