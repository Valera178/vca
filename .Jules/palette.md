## 2024-04-17 - Task List Keyboard Accessibility & Nested Interactions
**Learning:** When making large container components interactive (like a task list card), mapping semantic state (e.g., `aria-pressed={task.completed}`) provides immediate clarity to screen readers about the item's toggle state. Nested interactive elements (like specific buttons inside the container) must have `e.stopPropagation()` on both click and keydown events, and internal visual-only indicators should be hidden via `<div aria-hidden="true">` instead of using a non-semantic `<button>` to avoid nested interactive element accessibility tree issues.
**Action:** Always map toggled state to `aria-pressed`, ensure proper stop propagation for nested buttons, and replace inner decorative buttons with hidden `div`s when wrapping entire large items in an accessible `role="button"`.
