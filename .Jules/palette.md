## 2024-05-18 - Nested Interactive Elements in Large List Items
**Learning:** Making large list items (like tasks) act as a single interactive button (`role="button"`, `tabIndex={0}`) provides a large, accessible click target. However, having inner interactive tags (like `<button>` for checkboxes) inside this outer interactive element creates nested interactive element issues which breaks accessibility trees and keyboard navigation.
**Action:** Always convert inner visual-only controls (like checkboxes or icons inside the clickable area) to non-interactive elements (e.g., `<div aria-hidden="true">`) while relying on the parent container's keyboard and click events to handle the interaction. Any genuinely separate actions (like a "Решить" button) need `e.stopPropagation()` for both click and keydown events.
