## 2024-05-24 - Resolving Nested Interactive Elements in Custom List Items
**Learning:** When building custom interactive list items (like task toggles) using a large clickable container for better UX, placing visually distinct buttons (like a checkbox or solve button) inside it creates nested interactive element accessibility violations. Screen readers struggle with nested buttons, and click events can bubble unexpectedly.
**Action:** Convert the container into a full accessible button (`role="button"`, `tabIndex={0}`, `aria-pressed`, `onKeyDown`), change inner visual-only controls (like checkboxes) to non-interactive elements (`<div aria-hidden="true">`), and apply `e.stopPropagation()` on both click and keydown for any genuinely separate interactive child elements (like a "Solve" button).
