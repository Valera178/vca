## 2024-05-24 - Accessible Interactive List Containers
**Learning:** Found a common pattern where large clickable `div` containers (like task lists) contained nested `button` elements just for visuals (e.g., checkmarks), leading to invalid HTML/accessibility trees. Also, actual nested action buttons (like "Решить") lacked `stopPropagation` on both click and keydown, causing the outer container's toggle action to trigger unintentionally.
**Action:** Always verify nested elements within a clickable container. Convert visual-only nested interactive elements to `div aria-hidden="true"`. Ensure both `onClick` and `onKeyDown` have `e.stopPropagation()` on true nested interactive elements, and give the outer container `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler for Space/Enter to preserve the large clickable target area for UX.
