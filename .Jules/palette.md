## 2026-03-28 - Nested Interactive Elements in Complex UI Lists
**Learning:** When creating large interactive list items (like task cards) that contain visual-only indicators (like checkboxes or circles), do not use `<button>` for the visual indicators as it creates nested interactive elements which violate accessibility rules. Furthermore, any genuine secondary interactive child elements (like a "Solve" button) must stop propagation on both `onClick` and `onKeyDown` to prevent triggering the parent container's action.
**Action:** Always elevate the primary interaction to the list container itself using `role="button"`, `tabIndex={0}`, `onKeyDown` (for Enter/Space), and `aria-pressed`. Convert inner visual state indicators to `<div aria-hidden="true">`. Add `e.stopPropagation()` to both click and keydown handlers of separate interactive child components.
