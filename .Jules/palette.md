## 2024-04-29 - Accessible Interactive Containers
**Learning:** When making large click-target containers (like task lists) interactive, converting inner visual "toggle" controls (e.g., checkboxes or icons) from `<button>` to `<div aria-hidden="true">` prevents nested interactive element violations for screen readers. Simultaneously, genuinely separate interactive children (like nested action buttons) within that large target require explicit `e.stopPropagation()` on both click and keydown events to preserve the large click target without triggering parent container actions.
**Action:** Always apply `role="button"`, `tabIndex={0}`, and `onKeyDown` to the main container wrapper to make the entire large target accessible, replace inner visual-only controls with semantically hidden divs, and explicitly isolate any remaining functional nested buttons with stopPropagation.
