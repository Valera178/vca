## 2024-05-24 - Interactive List Item Accessibility and Nested Controls
**Learning:** In React applications with large interactive list items (like task containers), it is crucial to make the entire container accessible (`role="button"`, `tabIndex={0}`, keyboard handlers, and `aria-pressed` for toggle states). However, placing native `<button>` elements inside this interactive container creates a confusing nested structure for screen readers. Furthermore, interactive children (like nested Action buttons) need explicit `stopPropagation()` on both click AND keydown events to avoid unintentionally triggering the parent.
**Action:** When making large container components interactive for UX, explicitly add `role="button"` and `tabIndex={0}`, and change purely visual inner controls (like checkmark icons) to `<div aria-hidden="true">`. Always apply `e.stopPropagation()` to both `onClick` and `onKeyDown` of genuinely separate interactive child elements.
