## 2024-05-19 - Accessible Large Click Targets in List Items
**Learning:** When making large list items or container components interactive (like the task cards), we need to preserve the large click target area for UX. However, this creates nested interactive element issues for screen readers and keyboard users if the visual representation (like a checkbox) is also a button.
**Action:** Make the container `div` fully accessible by adding `role="button"`, `tabIndex={0}`, `onKeyDown` (for Enter/Space), and ARIA attributes like `aria-pressed`. Convert inner visual-only controls to non-interactive elements (e.g., `<div aria-hidden="true">`). Finally, ensure any genuinely separate interactive child elements (like specific action buttons inside the card) have `e.stopPropagation()` for both click and keydown events.
