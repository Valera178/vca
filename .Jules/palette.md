## 2026-04-05 - Accessible Interactive Cards with Nested Actions
**Learning:** Making a large container interactive (like a task card) requires careful handling of nested interactive elements. A common anti-pattern is nesting buttons inside the clickable div, which confuses screen readers and breaks keyboard navigation.
**Action:** Always add `role="button"`, `tabIndex={0}`, `onKeyDown` (for Enter/Space), and relevant ARIA attributes (like `aria-pressed`) to the main container. Convert inner visual-only controls (like checkmark icons) to non-interactive elements (e.g., `<div aria-hidden="true">`). For any genuinely separate interactive child elements (like specific actions), use `e.stopPropagation()` on both click and keydown events to prevent triggering the parent container's action.
