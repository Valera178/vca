## 2026-04-07 - Make task list items keyboard accessible
**Learning:** When making large container elements like task items interactive to preserve UX via a large click target area, adding the correct `role="button"` and `aria-pressed` with keyboard handlers is critical. Additionally, nesting semantic `<button>` elements within an interactive `div` causes nested interactive element accessibility issues.
**Action:** Always add keyboard handlers (`onKeyDown` for Enter/Space), `tabIndex={0}`, `role`, and `focus-visible` classes to interactive containers. Convert visual-only nested elements (like checkmark icons) to `<div aria-hidden="true">` to prevent nested focus elements. When a genuinely separate interactive button exists inside the container, attach `e.stopPropagation()` to both `onClick` and `onKeyDown` to prevent parent activation.
